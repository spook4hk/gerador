Gerador de Imagens — Faceless YouTube

Cole o trecho, clique em gerar e deixe rodar.

Chaves necessárias:
1. Groq (grátis): console.groq.com/keys → Create API Key
2. Leonardo: painel Leonardo → API → sua chave

Configuração

Preencha uma vez por sessão

Cole as URLs das suas imagens de referência que já estão no Leonardo.
Para pegar a URL: abra a imagem no Leonardo → clique com botão direito na imagem → "Copiar endereço da imagem".
O formato esperado é: https://cdn.leonardo.ai/users/.../imagem.png

Instruções do vídeo para o Groq

Ensine o Groq sobre o seu vídeo — história, personagens, estilo de cenas. Ele usa isso em todas as gerações.

Salve suas instruções em um arquivo .txt e suba aqui. O texto será passado para o Groq automaticamente.

Trecho para gerar

Cole o trecho da copy que quer gerar agora.
